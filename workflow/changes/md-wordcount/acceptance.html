Acceptance: Markdown word count script

Answer

scripts/wordcount.mjs counts the words of one Markdown file and skips code. All 48 tests pass and every criterion from AC-1 to AC-10 has a test.

  1. The script has no dependencies. It runs on Node 20 or newer.1
  2. Code blocks, inline code, front matter, URLs and HTML are not counted.2
  3. The CLI prints one number, or an error with exit code 1.

How does the script count words?

Diagram structure
  • Prepare text prep
  • Skip front matter front
  • Scan lines scan
  • Strip inline syntax inline
  • Count tokens count
  • front → scan
  • inline → count
  • prep → front
  • scan → inline · prose only
  1. Prepare text ↗

    Strip a leading BOM, turn CRLF into LF, normalize to NFC.

  2. Skip front matter ↗

    Drop a --- block that starts on line 1 and has a closing line.

  3. Scan lines ↗

    Drop fenced code, indented code at a block boundary, and reference definitions.

  4. Strip inline syntax ↗

    Remove code spans, comments, URLs, autolinks and tags. Keep link text and image alt.

  5. Count tokens ↗

    Count whitespace tokens with at least one letter or digit.

What did I decide without asking?

  • The test command is node --test scripts/wordcount.test.mjs. On Node 24, node --test scripts/ fails with Cannot find module.
  • The CLI rejects two or more arguments with the usage line.
  • Every removal is padded with spaces, so foo<br>bar counts as 2 words.
  • Code spans are removed before HTML comments, so a code span holding a comment opener stays literal.

What was not checked?

CI does not run these tests

CONSTRAINTS.md has no test check, so the trellis gate passes without running them. Add node --test scripts/wordcount.test.mjs as a check in a separate change.

Known limits

A 4-space indented list item after a blank line counts as code. Tag-like text is removed: in if x<y and z>w, the words y and z are not counted. The symlink case of the main-module check has no test.
